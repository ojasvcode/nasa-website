# 🚀 NASA Website Clone

A visually stunning **NASA-inspired space exploration website** built with **Vanilla JavaScript** — featuring an animated hero slider, mission showcase, solar system explorer, live stats counters, news section, and an Image of the Day panel.

---

## ✨ Features

- 🌌 **Animated Starfield Background** — 150 twinkling stars generated procedurally
- 🎬 **Auto-sliding Hero** — 5-slide carousel (Artemis, James Webb, Earth Science, Mars, ISS) with progress bar and dot navigation
- 🛸 **Active Missions Grid** — 6 NASA missions with status badges (Active, En Route, Upcoming)
- 🔢 **Animated Stat Counters** — 200+ missions, 65+ years, 350+ astronauts, 27K+ ISS orbits
- 🌍 **Solar System Explorer** — Horizontal scrollable planet cards with fun facts and distances
- 📰 **News Section** — Latest space news cards with date and excerpt
- 📸 **Image of the Day** — James Webb Telescope highlight panel
- 📧 **Newsletter Signup** — Subscribe form with animated confirmation
- 📱 **Fully Responsive** — Mobile hamburger menu, smooth scroll navigation
- ✨ **Scroll Reveal Animations** — Elements animate into view on scroll
- 🔗 **Active Nav Highlighting** — Current section highlighted in navbar

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v16+

### Installation & Run

```bash
git clone https://github.com/ojasvcode/nasa-website.git
cd nasa-website
npm install
npm run dev
```

Open **http://localhost:5173** in your browser.
